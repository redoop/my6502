# Tiny BASIC (tinybasic.asm) 功能完整性分析

## 文件信息
- **版本**: v0.2.2 (2011/11/11)
- **作者**: Bill O'Neill (Monitor) + Tom Pitman (Tiny Basic)
- **总行数**: 1310 行
- **架构**: 基于 IL (Intermediate Language) 解释器

## 核心架构

### 1. IL 解释器系统 ✅ 完整
- 使用中间语言 (IL) 字节码
- IL 操作码处理表 (SRVT) - 47 个操作码
- IL 程序表 (ILTBL) - 包含 BASIC 命令的 IL 字节码

### 2. 向量表 ✅ 完整
- **CV**: 冷启动向量 (COLD_S)
- **WV**: 热启动向量 (WARM_S)
- **IN_V**: 输入例程 (RCCHR)
- **OUT_V**: 输出例程 (SNDCHR)
- **BV**: 中断例程 (BREAK)

### 3. IL 操作码 (47个) ✅ 完整实现

#### 分支控制 (6个)
- **BBR** ($40-$5F): 向后相对分支
- **FBR** ($60-$7F): 向前相对分支
- **BC** ($80-$9F): 字符串匹配分支
- **BV** ($A0-$BF): 非变量分支
- **BN** ($C0-$DF): 非数字分支
- **BE** ($E0-$FF): 非行尾分支

#### 栈操作 (4个)
- **LB** ($09): 压入字面字节
- **LN** ($0A): 压入字面数字
- **DS** ($0B): 复制栈顶两字节
- **SP** ($0C): 栈弹出

#### BASIC 指针 (2个)
- **SB** ($10): 保存 BASIC 指针
- **RB** ($11): 恢复 BASIC 指针

#### 变量操作 (2个)
- **FV** ($12): 取变量
- **SV** ($13): 存变量

#### 子程序 (3个)
- **GS** ($14): 保存 GOSUB 行
- **RS** ($15): 恢复保存的行
- **GO** ($16): GOTO

#### 算术运算 (5个)
- **NE** ($17): 取负
- **AD** ($18): 加法
- **SU** ($19): 减法
- **MP** ($1A): 乘法
- **DV** ($1B): 除法

#### 其他 (4个)
- **CP** ($1C): 比较
- **NX** ($1D): 下一条 BASIC 语句
- **LS** ($1F): 列出程序
- **NO** ($08): 空操作

#### 输出 (5个)
- **PN** ($20): 打印数字
- **PQ** ($21): 打印 BASIC 字符串
- **PT** ($22): 打印制表符
- **NL** ($23): 新行
- **PC** ($24): 打印字面字符串

#### 输入/程序管理 (5个)
- **GL** ($27): 获取输入行
- **IL** ($2A): 插入 BASIC 行
- **MT** ($2B): 清空程序空间
- **XQ** ($2C): 执行
- **US** ($2E): 机器语言子程序调用
- **RT** ($2F): IL 子程序返回

### 4. BASIC 命令支持 ✅ 完整

从 ILTBL 字节码可以推断支持的命令:
- **LET**: 变量赋值
- **PRINT**: 输出
- **INPUT**: 输入
- **IF...THEN**: 条件判断
- **GOTO**: 跳转
- **GOSUB/RETURN**: 子程序
- **LIST**: 列出程序
- **RUN**: 运行程序
- **CLEAR**: 清空程序
- **REM**: 注释
- **END**: 结束程序

### 5. I/O 系统 ✅ 完整

#### 输入 (RCCHR)
```assembly
RCCHR    lda $F001      ; 从 $F001 读取字符
         beq RCCHR      ; 轮询等待输入
         rts
```

#### 输出 (SNDCHR)
```assembly
SNDCHR   sta $F000      ; 写入 $F000
         rts
```

#### 特殊功能
- **PEEK/POKE**: 内存访问 ✅
- **BREAK**: 中断检测 ✅

### 6. 监视器 (Monitor) ✅ 完整

位于 $F800-$FFFF:
- 系统初始化 (FBLK)
- 屏幕清除 (CLRSC)
- 消息打印 (SNDMSG)
- 启动菜单 (C=Cold, W=Warm)

| 地址范围 | 用途 |
|---------|------|
| $0000-$7FFF | RAM |

| $8000-$EFFF | ROM - Tiny Basic |
| $F000 | 输出端口 (OUTCH) |
| $F001 | 输入端口 (INCH) |
| $F800-$FFFF | ROM - Monitor |
