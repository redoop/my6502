## 已知问题

### 1. 调试输出混杂
**现象**：CPU的$display调试信息混在正常输出中
```
[JSR] cycle 1: Push PCH=03 to SP=ff, PC=030c
M[RTS] EXECUTE: SP=fd, SP+1=fe
```

**影响**：用户体验不佳，但不影响功能

**解决方案**：
- 方案1：注释掉cpu_6502.sv中的$display语句
- 方案2：使用条件编译（`ifdef DEBUG）
- 方案3：重定向stderr到/dev/null（临时方案）

### 2. 功能限制
- 仅支持PRINT命令
- 不支持变量和表达式
- 不支持循环和条件语句
