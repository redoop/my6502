
## 已知问题

### 1. JSR/RTS 问题 ⚠️
**现象**: 某些情况下导致无限循环
**影响**: Phase 2 的 2 个测试失败
**解决方案**: 需要调试栈指针和返回地址

### 2. 循环输出 ⚠️
**现象**: 字符串输出循环
**影响**: Phase 7 的 1 个测试失败
**解决方案**: 需要正确的循环终止条件
