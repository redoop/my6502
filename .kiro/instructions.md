# Project Structure Rules

## Directory Organization - ALWAYS FOLLOW

- **`src/`** - All source code goes here
- **`docs/`** - All documentation goes here  
- **`scripts/`** - All scripts go here
- **Root directory** - Keep clean, only core config files

## Branch Information

- **`main`** - Chisel/Scala implementation
- **`systemverilog`** - Pure SystemVerilog implementation (nes_system.sv only)

## Important Notes

- Never create temporary files or documents in root directory
- All new documentation must go in `docs/`
- All new scripts must go in `scripts/`
- All new code must go in `src/`
