## 🔧 手动测试APU
可以修改代码手动设置APU寄存器来测试：

```systemverilog
// 在nes_system.sv的reset后添加
if (cycles == 1000) begin
    apu_pulse1[0] <= 8'b10111111;  // 50% duty, constant volume 15
    apu_pulse1[2] <= 8'hFE;         // Period low
    apu_pulse1[3] <= 8'h00;         // Period high, length
    apu_write_pulse1_3 <= 1;
    apu_status <= 8'h01;            // Enable pulse 1
end
```

这会生成一个低频方波音调。
