## 技术细节

### MMC1 PRG映射（模式11）
```
$8000-$BFFF: 可切换bank (prg_bank[3:0])
$C000-$FFFF: 固定最后16KB (bank 7)

$FF77 → Bank 7, offset $3F77
      → ROM address $1FF77
      → 数据 $20 (JSR)
```

### CPU卡住的位置
```
PC = $FF77
预期指令: JSR $xxxx (3字节)
实际行为: 单字节循环（可能读到$00或其他）
```
