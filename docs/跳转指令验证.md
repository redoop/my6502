## 修复的指令

### 1. JSR (Jump to Subroutine) - $20 ✅
**功能**: 跳转到子程序并压栈返回地址

**修复内容**:
- EXECUTE: 压栈PC高字节，初始化cycle_count
- MEMORY cycle 1: 压栈PC低字节
- MEMORY cycle 2: 读取目标地址高字节
- WRITEBACK: 跳转到目标地址

**周期**: 6个周期

### 2. RTS (Return from Subroutine) - $60 ✅
**功能**: 从子程序返回

**修复内容**:
- EXECUTE: 开始从栈读取，初始化cycle_count
- MEMORY cycle 1: 读取PC低字节
- MEMORY cycle 2: 读取PC高字节
- WRITEBACK: 跳转到返回地址+1

**周期**: 6个周期

**注意**: RTS返回到JSR的下一条指令（PC+1）

### 3. JMP indirect - $6C ✅
**功能**: 通过间接地址跳转

**修复内容**:
- EXECUTE: 读取间接地址，初始化cycle_count
- MEMORY cycle 1: 读取目标地址低字节
- MEMORY cycle 2: 读取目标地址高字节
- WRITEBACK: 跳转到目标地址

**周期**: 5个周期

### 4. JMP absolute - $4C ✅
**功能**: 直接跳转

**状态**: 已正确实现，无需修改

**周期**: 3个周期

## 实现模式

所有多周期跳转指令遵循相同模式：

```systemverilog
// EXECUTE阶段
cycle_count <= 1;  // 启动多周期

// MEMORY阶段
case (cycle_count)
    1: begin
        // 第一个额外周期
        cycle_count <= 2;
    end
    2: begin
        // 第二个额外周期
        cycle_count <= 0;  // 完成
    end
endcase

// WRITEBACK阶段
PC <= target_address;  // 完成跳转
```
